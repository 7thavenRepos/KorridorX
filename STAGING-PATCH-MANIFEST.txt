KorridorX Ubuntu Staging Deployment Patch

Add these files at the matching paths in the KorridorX repository:

- .env.staging.example
- docker-compose.staging.yml
- deploy/nginx/korridorx-staging.conf
- scripts/deploy/staging-deploy.sh
- scripts/deploy/staging-rollback.sh
- scripts/deploy/staging-smoke-test.sh
- Docs/StagingDeployment.md

This patch does not replace the existing development Docker Compose configuration.
Review Docs/StagingDeployment.md before running any server command.
